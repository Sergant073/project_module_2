# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта
Исследование поведения пользователей для выявления факторов лояльности и повторных покупок

## Цель проекта
Выявление ключевых факторов, влияющих на возвращение пользователей на платформу

## Методология
* Сбор и предобработка данных
* Построение профиля пользователя
* Исследовательский анализ данных
* Выявление значимых факторов
* Формулировка рекомендаций

## Основные метрики
* **avg_revenue** - средняя выручка на пользователя
* **return_rate** - доля вернувшихся пользователей
* **avg_orders** - среднее количество заказов
* **avg_days_between** - средний интервал между заказами

## Ключевые выводы
* Выявлены значимые факторы влияния на возвратность
* Определены целевые сегменты пользователей
* Установлены основные драйверы лояльности
